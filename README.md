# actions

Monorepo for my GitHub Actions. Branches:

- [`v0`](https://github.com/anttiharju/actions/tree/v0) offers no stability guarantees, it's bleeding edge for whatever I happen to be working on.
- [`v1`](https://github.com/anttiharju/actions/tree/v1) was released after the conclusion of [`vmatch`](https://github.com/anttiharju/vmatch) and can be considered safe to refer to.

Locking refs to this repo to a SHA is not recommended, as sometimes I rewrite history here. Feel free to copy the actions here to your own repository per the [MIT License](./LICENSE).
